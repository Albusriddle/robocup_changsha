## 2. 最终策略

`entry.py` 暴露 `build_policy(context)` → `CoverageRulePolicy(load_config(context.artifact_dir), context.artifact_dir)`。
每台机器人每局一个实例；`reset` 清空全部每局状态；所有决策只使用 `AgentObservation` 的合法字段。

每步四件事：

1. **速度估计**：对可见且存在的目标，用相邻步相对位置差分估计相对速度 `rel_vel = (rel_t − rel_{t−1}) / dt`；
   目标出视野则不跨步差分，沿用上次估计。**目标速度在协议中不可直接观测**，这是唯一合法来源。
2. **目标选择**：对可见目标按预测末态相对距离 `|rel + rel_vel·dt·(T − step)|` 升序排序；
   开启分工时，若有"更近（或等距且编号更小）的**可见**队友"更接近该目标，则让位给下一个候选。
   **E007 证据（`predict_horizon="zero"` 消融）**：预测末态选择与"就地就近选择"**无显著差异**
   （块 A ΔS +1.000、块 B −1.333、公开 0.000；两块 CI95 均与对照重叠、符号跨块翻转，两块合计反而低 0.333）。
   保留默认 `remaining` 的依据是**零行为变更 + 方向不确定**，而**不是**"更优"。
3. **控制律**：`u = clip(K · rel, −1, 1)`，`K = 20`，即**分量饱和驱动**。
   动作箱是 `[-1,1]²`，而物理里 `force = drive_force × action`，因此 `|u|` 的上限是 **√2 而不是 1**（见第 3 节）。
   无可见目标时朝场地中心驱动（提高与随机目标的相遇概率）。
4. **轻量避碰 + 动作保险链**：仅对 `distance < safety_radius = 0.12` 的可见队友叠加排斥项 `(r−d)/r · 4.0 · away/|away|`；
   最后 `np.nan_to_num → np.clip(−1,1) → np.ascontiguousarray(float32)`，返回 `(2,)` 的 `float32`。

冻结超参数（= `artifacts/rule-config.json`，`submission.yaml` 已登记其 SHA-256 与字节数）：
`control_gain 20.0`、`predict_horizon "remaining"`、`unit_magnitude false`、`deconflict true`、
`safety_radius 0.12`、`safety_gain 4.0`、`memory true`、`blind_action "center"`、`clip_eps 1e-06`。
`load_config` 对缺失/损坏/非法配置一律回退默认值且不抛异常（`tools_local/robustness_check.py` 已覆盖）。

## 3. 设计依据：这个任务的分数由什么决定

本节数字全部由官方环境（Python 3.12 + mpe2 1.1.1）实测，证据脚本在仓库外的开发笔记中（`notes/tools/`）。

### 3.1 行程受限：一局 10 步只够走 0.25–0.35 m

`mpe2` 的积分是**先位置后速度**：`p += v·dt` → `v *= 0.75` → `v += u·dt`（`|v| ≤ 1`）。
实测恒定动作 10 步累计位移：

| 动作 | `|u|` | 10 步累计位移 |
| --- | --- | --- |
| `[1, 0]`（轴向满推） | 1.000 | **0.2490 m** |
| `[1, 1]`（对角满推） | **1.414** | **0.3522 m** |
| `[0.5, 0]` | 0.500 | 0.1245 m |

位移与 `|u|` 成正比；覆盖判定半径只有 0.15 m，感知半径 0.6 m。因此"能不能得分"几乎完全由
**开局几何 + 到达速度**决定。实测每步平均覆盖率曲线单调上升（块 A 的 basic：
`0.040 0.060 0.100 0.120 0.140 0.160 0.207 0.280 0.327 0.347`），说明第 10 步机器人仍在赶路，
**"到位后如何驻留"价值极小**（每步位移约 0.035 m，远小于 0.15 m 的覆盖半径）。

### 3.2 用满动作箱（√2）是本方案最大的单点优势

单位幅度驱动（`rel/|rel|`）只能拿到 0.249 m，分量饱和能拿 0.352 m（+41%）；
可达面积 ∝ (位移 + 0.15)²，约 1.58 倍可达目标对数。E001 实测三口径一致：
**ΔS = +16.400（块 A）/ +16.934（块 B）/ +38.334（公开）**，且单位向量组块 B 仅 113.333（跌破 130）。
这也解释了为什么"简单规则"能明显高于官方学习基线：官方 P902 rule（175.00）与"就近 + 单位向量"
在公开套件上的复现值（183.333）高度吻合，而分量饱和能到 221.667。

### 3.3 几何上界与学习组件的取舍（为什么不做学习组件）

用"提前知道整局目标轨迹 + 最优直线满推 + 逐步最大匹配"算出的**几何上界**（与策略无关，只取决于初始几何与目标轨迹）：

| 种子块 | basic J_max | coop J_max | S_max | 本方案实测 S | 达到同块上界 |
| --- | --- | --- | --- | --- | --- |
| 开发探测集（1001,1002+5001–5040 / 2001,2002+6001–6040，42 例/组） | 0.1190 | 0.1651 | 142.1 | — | — |
| 块 A（7001–7050 / 8001–8050） | 0.1767 | 0.1933 | **185.0** | 184.667 | **99.8%** |
| 块 B（5001–5050 / 6001–6050） | 0.1153 | 0.1533 | **134.3** | 130.267 | **97.0%** |
| 公开套件 4 例 | — | — | 225.0 | 221.667 | 98.5% |

**表中每个百分比都在同一批种子内取分子/分母**（块 A 的实测 S 除以块 A 的上界，不跨块换算）。
可见"剩余空间"完全取决于种子块：块 A 只剩 0.33 分，块 B 还有 4.03 分。

结论：剩余空间约 7%，而官方 PPO 基线（P903，1M 步）在同样公开套件上只有 116.67，
本地对模板模型实跑为 66.67（basic 组 0 覆盖）。权衡后**不投入学习组件**（`SCOPE_LEARNING=off`），
把预算放在有效性与记录质量上。这是**基于实测的取舍**：若后续尝试，建议路线是
"规则给基础动作 + 小型网络只学残差/分配打分器"，并用 `--seed-block both` 做双块复现，而不是从零 PPO。

### 3.4 碰撞的代价是双重的

每步惩罚 `−0.2·K_t`；同时实测深度接触（中心距 0.06，半径和 0.10）会把机器人以 **0.40 m/s** 弹开
（中心距 0.02 时达 0.80 m/s，而阻尼 0.75/步，需要好几步才能收回），破坏后续数步的几何。
但过度避碰同样掉分：E003 扫 0.0/0.08/0.12/0.16 四档在统计上不可区分，`0.12` 按"两块合计最高"保留。

**E004 的机制（诊断计数器实测，非推断）**：`entry.py` 的记忆外推分支在 6000 次 act 中只被触发 **3 次**
（块 A 0/3000、块 B 3/3000），且这三次都落在**同一段连续步**（uniform seed 5049、agent 1、step 1–3）。
在这些步上，记忆外推路径与"朝中心盲走"回退路径给出的动作**逐位相同**（`[1.0, -1.0]`：`K=20`
饱和后两者落到同一个角点）。因此 `memory` 在本任务下**无效且不可检验** —— 不是"没测出差异"，
而是这条分支几乎不可达、可达时又与回退等价。计数器为只读记账，已用 208 局逐位比对证明行为不变。

**动作量化（F5，解释为何 12 次消融大多为 null）**：默认控制律 `u = clip(20·rel, −1, 1)` 在任一分量
`|rel| ≥ 0.05 m` 时即饱和，而实测 t=0 到最近目标的平均距离是 **0.3668 m**，远大于 0.05 m。6240 次 act 实测：

- **66.603%** 的动作两个分量都饱和（`|u| = √2`），**96.074%** 至少一个分量饱和；
- 频次 Top-4 全部是**角点**，且其频次合计恰好等于"双分量饱和"的次数（块 A：554+472+465+432 = 1923）；
  第 5–10 名的频次都只有 **2** 次；
- 不同动作取值个数：块 A **1065** / 块 B **929** / 公开 **35**（长尾来自极少数接近目标时的微调）。

因此 E002/E003/E005/E006/E007 多为 null 是**结构性结果**：动作几乎总被量化到 4 个角点之一，

这条分析把"没发现差异"升级为"符合结构性预期"，也是本提交保留默认超参数的主要依据。

## 5. 跨块差异的归因（已解释；含剩余不确定性）

同一份代码、同一套配置在两个固定私有块上的分数相差约 54 分。**这个差异已被归因到初始几何**，
而不是策略抖动或工具误差：用与策略无关的几何上界探针（真值目标轨迹 + 最优固定朝向 + 逐步最大匹配）
在**相同种子**上计算上界，得到块 A **185.0**、块 B **134.3** —— 两块上界本身就相差 50.7 分，
与实测差 54.4 分同量级。

| | 块 A（7001–7050 / 8001–8050） | 块 B（5001–5050 / 6001–6050） |
| --- | --- | --- |
| 实测 S | 184.667 | 130.267 |
| 同块几何上界 S_max | 185.0 | 134.3 |
| 达到同块上界 | **99.8%** | **97.0%** |
| ΔS(A−B)：实测 / 上界 | +54.400 / +50.7 | |
| CI95 是否重叠 | 否（12 次运行中 10 次不重叠；例外为 `control_gain=5.0` 与 E007，两次重叠都源于块间均值差缩小、而非方差变大） | |
| 组均值（basic / coop） | 0.176 / 0.193 | 0.111 / 0.150 |

含义与后果：

1. **块间差异主要由初始几何承载**：两块上界相差 50.7 分，实测相差 54.4 分；策略在两块上的
   残差分别是 0.33 分与 4.03 分，这才是策略本身可争取的部分。
2. **绝对值不可跨块比较**；单块上 ≤1 分、且换块翻符号的差异（如 `safety_radius=0.16`、
   `control_gain=10`）只能判"无显著差异"。只看单块会得出"避碰半径必须精调 0.12"这类**错误结论**。
3. 公开套件口径（仅 4 个场景）CI95 宽达 [76.667, 366.667]，并把 E001 的收益放大到 +38.3
   （私有块仅 +16~17），**不能作为判据**。
4. **剩余风险**：块 B 的 130.267 已非常接近其自身上界 134.3，策略在该块上几乎没有提升空间；
   若正式核验的种子偏向"几何不利"的一侧，分数就会落在 130 附近。这属于任务方差
   （单组仅 2 个场景、单局 J 取值 0–0.6），不是实现缺陷，但必须如实披露。
5. **对官方核验成绩的预测区间**见第 1 节的第二张表（F2）：套件级重抽样给出的 P5/P50/P95
   比"50 例/组的 CI95"宽得多，后者不能用来预测核验成绩。

## 6. 失败场景与已知局限

- **开局几何不利时无法得分**：一台机器人一局只能走 0.35 m，若 3 个目标都不在可达范围内，
  该机器人本局贡献为 0（实测存在大量 0 分场景），这是任务设计使然。
- **目标不可见时只能盲走（F6 实测的规模）**：全盲"机器人×局"占 **32.83%**（197/600），
  盲走步占全部 act 的 **41.35%**（2481/6000）；t=0 平均只能看到 **0.6567** 个目标、
  到最近目标的平均距离 **0.3668 m**，且 **48.17%** 的 agent-局在 t=0 完全看不到任何目标。
  盲走步直方图（step 0→9，两块合计）`[289,281,275,267,257,248,235,222,210,197]` 单调递减，
  前 5 步占全部盲走的 **55.18%** ⇒ 盲走主因是"开局看不到目标"，而不是中途丢失目标。
  目标速度在协议中不可观测，出视野后只能靠记忆外推，而 E004 已证明记忆分支几乎不可达；
  E005 只比较了"朝中心"与"原地"两个朴素选项，因此**盲走方向是目前唯一仍有结构空间的部分**
  ——本轮按甲类要求**未做任何行为改动**；若后续要动，属乙类修改，必须重跑全套实验并重建全部表格。
- **跨局状态约束**：本策略不维护任何跨局状态（每台机器人一个实例，`reset` 全清），
  这是官方明确要求（"不得跨评测回合适应测试集"）且必须长期守住的约束。
- **`local_preview` 不检查阶段超时**：Windows 无 `setitimer/SIGALRM/ITIMER_REAL`，
  本地评测的 load/act/episode 限额不生效。实测 `act` 单步 mean ≈0.03 ms、p95 约 0.045–0.072 ms、
  max 约 0.09–0.41 ms（独立复核 pooled 实测；限额 1000 ms），
  风险极低，但**本地不构成对超时的证明**。
- **未做规模拓展**：4v5 / 5v7 未运行（`SCOPE_EXTRA_EXPERIMENTS=off`）。
  实现上不假设具体数量（按掩码处理，容量 A=B=8），但**没有实测证据**，故不宣称泛化能力。
- **模板学习基线分数不一致**：官方文档记 P903 = 116.67，本地对模板模型实跑为 66.67（basic 组 0 覆盖）。
  差异原因未定论（可能 checkpoint 或平台差异），**已如实记录，且不用于任何结论**。

## 10. 偏差记录（实现与任务契约文字的差异，如实披露）

1. **避碰项的符号**：任务契约把排斥项写成 `u -= f·(self_pos − peer_pos)/d`，但观测里只有队友相对量
   `peers[k][:2] = peer_abs − self_abs`，故 `(self_pos − peer_pos)` 恰等于 `−peers[k][:2]`；
   按字面落地会变成"朝队友靠近"（吸引），与避碰语义相反。
   `entry.py` 按**排斥**落地（`away = −peer_rel/d`），并在 `entry.py:283-291` 注释说明。
   实测支撑（同一源码只改该行运算符，30 例/组）：排斥 J 和 2.4533 > 吸引 2.4489 = 关闭避碰，
   且排斥的碰撞更少；公开 4 例两种写法同分（该例未触发差异）。**保留排斥实现。**
2. **配置取值域**：`safety_radius = 0.0`（关闭避碰）是合法的消融取值，
   `load_config` 的区间判定采用闭区间 `low ≤ v ≤ high`，以免把消融配置静默清洗成默认值。
3. **E005 假设未获证实**：开发方案中"无可见目标时朝中心走更好"的假设在双口径实测中**未得到支持**，
   实现仍保留 `blind_action="center"`（与 `"stay"` 无显著差异，且在块 A 与公开口径上逐位不差）。

## 12. 结论

在冻结参数下，这是一个**由行程预算主导**的任务：一局 10 步只能走 0.249 m（轴向）或 0.352 m（对角），
而覆盖判定半径 0.15 m。方案的核心是**用满动作箱的分量饱和驱动（√2）**，配合预测末态的一对一目标选择与
轻量避碰；它已贴住同块几何上界的 **块 A 99.8% / 块 B 97.0% / 公开 98.5%**（每个百分比都在同一批种子内取分子分母）。
其中"预测末态选择"本身**未获显著优势**（E007 与"就地就近"无显著差异，两块 CI 重叠且符号跨块翻转），
保留默认配置是因为它零行为变更、方向不确定，而不是因为它更优。
学习组件在这个任务上的边际收益（≤ 7%）不足以抵消其复杂性与
有效性风险，故本提交为纯规则方法。

需要如实说明的三点：① 公开套件成绩（221.667）明显偏乐观，私有双块口径为 184.667 / 130.267，
**跨块差异巨大且不可跨块比较**（16 块场景池的块均值 S(50/50) ∈ [130.3, 186.3]）；
② 按"核验套件同构（2 场景/组）"重抽样，成绩预测区间 P5/P50/P95 ≈ 41.7 / 158.3 / 300.0，
`P(S≥130) ≈ 0.65`；③ 全部数字均为本地预览结果，最终以组织方统一核验为准。
